AI CV EVALUATOR FOR RECRUITERS

Evaluate CVs against job descriptions with evidence, not keyword guesses.

Mimir is an AI CV evaluator built for recruiters who need to understand not only whether a candidate appears to match a role, but what the CV actually proves. What makes Mimir a different kind of CV evaluator?

Many CV matching tools produce a percentage after comparing keywords or asking a language model for a judgement. A percentage can be useful, but recruiters still need to know why the candidate received it. Mimir separates interpretation from scoring so the numerical result does not come directly from the AI model.

01 · INTERPRET

Understand the requirement

The job description is structured into explicit requirements before candidate evidence is assessed.

02 · VERIFY

Trace the proof

Text quotes and approved visual artefacts are connected to claims, with uncertainty kept visible.

03 · SCORE

Apply fixed policy

Deterministic JavaScript converts verified evidence states into a reproducible score lineage.

CV evaluation against a real job description

Mimir evaluates the candidate in the context of a specific role. It can distinguish a technology mention from hands-on delivery, support from design ownership, participation from leadership, and a related capability from an exact mandatory requirement. When the CV does not establish a claim, Mimir can mark it for verification instead of silently inventing certainty.

Text and visual CV evidence

Technical candidates often include architecture diagrams, cloud decision flows, topology drawings and solution artefacts in their CVs. Mimir's document intelligence can use substantive visuals alongside extracted PDF or DOCX text, so a diagram is not automatically discarded just because it is not represented in the document's text layer.

For recruiters, not autonomous rejection

Mimir is designed as decision support. It surfaces evidence, gaps, caveats and questions for a recruiter to review. The final hiring decision remains human-controlled.

Core principle: AI interprets. Mimir verifies. JavaScript scores. Humans decide.
